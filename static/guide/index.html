CHAPITRE 01

Choisir le van de départ d'une tournée

Distribution › Tournées Pour : administrateur, planificateur
Où trouver cet écran
Menu de gauche
Distribution›Tournées

Cliquez sur Distribution pour ouvrir la liste, puis sur Tournées. Le bouton Nouvelle Tournée est en haut à droite de la page.

Chaque tournée part d'un van. Vous le choisissez dans le formulaire de la tournée, et il est reporté sur la fiche du livreur.

  1. Cliquez sur Nouvelle Tournée, ou sur le bouton Modifier d'une tournée existante.
  2. Choisissez le livreur.
  3. Ouvrez Entrepôt de départ et choisissez le van.
    • Seuls les vans actifs sont proposés : les entrepôts dont le code contient « van ».
    • Si vous laissez le champ vide, la tournée prend le van inscrit sur la fiche du livreur.
  4. Enregistrez.

Ce qui se passe ensuite

  • Si la tournée est planifiée ou en cours, le van choisi est inscrit sur la fiche du livreur. Sa prochaine tournée sera pré-remplie avec ce van.
  • Modifier une tournée terminée ou clôturée ne change pas le van actuel du livreur.
  • En modification, laisser le champ vide ne supprime pas le van déjà enregistré.
  1. Pour vérifier, cliquez sur Voir les détails : la ligne Entrepôt de départ affiche le code et le nom du van.
Tournées existantesLes tournées créées avant la mise à jour ont reçu le van qui figurait sur la fiche de leur livreur.

Dans la page, descendez sous les filtres de date : le bloc Indicateurs de performance est le premier tableau.

Le bloc Indicateurs de performance suit les filtres du haut de la page : la période (par défaut le mois en cours) et le livreur. Les quatre tuiles donnent le total de l'équipe ; le tableau donne le détail par vendeur.

  1. Lisez d'abord les tuiles : le résultat de toute l'équipe, avec le détail du calcul sous chaque taux.
  2. Descendez dans le tableau pour comparer les vendeurs. La couleur de la pastille indique le niveau : rouge faible, orange moyen, vert bon.

Changement de calcul des objectifsLe CA réalisé d'un objectif compte maintenant les ventes de tournée et les commandes prises, en TTC, sans les commandes annulées. Avant, seules les ventes de tournée comptaient : le taux de réalisation des prévendeurs augmente donc. Livrer une commande ne crée pas de vente, rien n'est compté deux fois.
  • Un prévendeur et un livreur sont mesurés avec les mêmes règles.
  • Un tiret « - » signifie que le taux ne peut pas être calculé : rien de planifié, aucune visite ou aucune commande.
  • La période choisie ne peut pas dépasser deux ans.
CHAPITRE 03

Chiffre d'affaires par vendeur, mois par mois

Rapports & Analyses › Statistiques Livreurs Pour : responsable commercial
Où trouver cet écran
Menu de gauche
Rapports & Analyses›Statistiques Livreurs

Même page que le chapitre 02 : le bloc Chiffre d'affaires par vendeur se trouve juste sous les indicateurs.

  1. Choisissez l'année. Ce tableau couvre toujours l'année entière : il ignore les dates du haut de la page, mais suit le filtre livreur.
  2. Choisissez ce que vous voulez voir : Total (ventes de tournée et commandes), Ventes de tournée seulement, ou Commandes seulement (sans les commandes annulées).

CHAPITRE 04

Inventaire : compter sur papier, saisir en une fois

Gestion de stock › Inventaire Pour : magasinier, gestionnaire de stock
Où trouver cet écran
Menu de gauche
Gestion de stock›Inventaire

La page s'ouvre sur l'onglet Mes Sessions. Les boutons Feuille de comptage, Saisie en masse et Exporter apparaissent après avoir ouvert une session.

Le comptage se fait en trois temps : imprimer la feuille, compter dans le dépôt, puis ressaisir la feuille en une seule fois. Les numéros de ligne sont les mêmes sur la feuille et à l'écran.

  1. Dans Mes Sessions, cliquez sur Ouvrir à côté d'une session en brouillon ou en cours. Les onglets Comptage et Détails demandent une session ouverte ; sinon un message vous l'indique.
  1. Une fois la session ouverte, trois nouveaux boutons apparaissent : Feuille de comptage, Saisie en masse et Exporter.

Imprimer la feuille de comptage

  1. Cliquez sur Feuille de comptage. La feuille A4 s'ouvre dans un nouvel onglet.
  2. Cliquez sur Imprimer, ou faites Ctrl + P. Restants uniquement n'affiche que les produits pas encore comptés.
  3. Dans le dépôt, notez pour chaque produit les cartons et les unités. Écrivez 0 si le produit est absent.
  4. Les produits déjà saisis apparaissent en gris avec la mention (déjà saisi).
Imprimer une seule catégorieOuvrez d'abord la saisie en masse, choisissez la catégorie ou « Restants uniquement », puis cliquez sur Feuille de comptage : la feuille reprend les mêmes filtres.

Ressaisir la feuille : saisie en masse

  1. Cliquez sur Saisie en masse. Filtrez si besoin par Catégorie, par Afficher (tous ou restants) ou avec Rechercher (N°, référence, désignation, code-barres).
  2. Repérez la ligne par son N° : c'est le même que sur la feuille papier.
  3. Tapez la quantité dans Quantité comptée, ou remplissez Cartons + unités pour que le total soit calculé. Entrée passe à la ligne suivante.
  4. Suivez la colonne État pour voir où en est chaque ligne.
  5. Cliquez sur Enregistrer la saisie. Toutes les lignes partent en une fois ; les lignes en erreur restent affichées pour être corrigées.
À compter Compté Modifié À effacer Erreur

Coller depuis Excel

  1. Cliquez sur Coller depuis Excel.
  2. Collez deux colonnes : la référence (ou le code-barres, ou le N° de ligne), puis la quantité. Séparateurs acceptés : tabulation, ; ou ,.
  3. Cliquez sur Remplir le tableau, vérifiez les lignes, puis Enregistrer la saisie.

Exporter

La session en Excel

Cliquez sur Exporter. Le fichier inventaire_<numéro>.xlsx donne, pour chaque produit, la quantité théorique, la quantité comptée et l'écart. Tant que la session est ouverte, tous les produits sont listés.

Valider

Valider l'inventaire

Si des produits ne sont pas comptés, la validation est refusée et le message donne le nombre et la liste des produits manquants. La validation est appliquée en entier ou pas du tout : jamais d'ajustement de stock à moitié.

CHAPITRE 05

Modifier une commande directement sur le bon

Application mobile Pour : prévendeur, livreur
Où trouver cet écran
Prévendeur
Accueil›Historique›onglet Tournées›Voir tous les détails›le client›Voir tous les produits›Modifier la commande
Livreur
Accueil›Commandes à livrer›Modifier la commande

Sur l'écran Accueil de l'application, descendez jusqu'aux Actions rapides : Commandes à livrer et Historique sont en bas de la liste. Le bouton Modifier la commande est en haut du bon de commande.

Le client change d'avis devant vous : il ajoute un produit, en retire un ou change une quantité. Vous ouvrez le bon de commande sur le téléphone, vous le corrigez, et la modification part au serveur à la prochaine synchronisation. Le prévendeur et le livreur ont chacun leur bouton Modifier la commande.

Prévendeur : depuis le bon de commande

  1. Ouvrez Historique, onglet Tournées, puis Voir tous les détails sur la tournée du jour.
  2. Touchez le client, puis Voir tous les produits sous la commande : le bon s'ouvre.
  3. Appuyez sur Modifier la commande, en haut du bon. Le bouton n'apparaît que si la tournée est en cours et que la commande n'est ni livrée, ni annulée, ni entièrement payée. Sinon, un message avec un cadenas en donne la raison, par exemple « Cette commande est déjà livrée ».
  4. Changez les quantités (en unités ou en cartons), supprimez une ligne avec la corbeille ou ajoutez un produit. Les montants sont affichés TTC, comme sur le bon, et le total se met à jour.
  5. Appuyez sur Modifier commande, en bas, pour enregistrer ; ou sur Annuler pour tout laisser comme avant.

Livreur : depuis Commandes à livrer

Prévendeur

Depuis le bon de commande

  1. Ouvrez le bon : Historique › Tournées › Voir tous les détails › le client › Voir tous les produits.
  2. Appuyez sur Modifier la commande. Le bouton n'apparaît que si la tournée est en cours.
  3. Changez les produits ou les quantités, puis appuyez sur Modifier commande.

Si vous modifiez plusieurs fois avant la synchronisation, seule la dernière version est envoyée.

Livreur

Depuis Commandes à livrer

  1. Ouvrez Commandes à livrer, puis la commande.
  2. Appuyez sur Modifier la commande. Changez les quantités, retirez une ligne ou utilisez Ajouter un produit pour prendre un produit du van.
  3. Vérifiez le Nouveau total, appuyez sur Enregistrer, puis livrez normalement.

La modification est envoyée avant la livraison.

Le trajet d'une modification

Vous modifiezSur le téléphone, même sans réseau.
En attente d'envoiLa modification est gardée sur le téléphone.
SynchronisationElle part dès que le réseau revient.
Le serveur vérifieIl applique les mêmes règles que le téléphone.

Acceptée

La commande est à jour sur le serveur. Chaque modification est tracée dans la commande : auteur, date et changements.

Refusée

Un bandeau rouge s'affiche sur la commande avec le motif. La modification n'est pas renvoyée en boucle : corrigez la commande ou voyez avec l'administrateur.

Modification refusée par le serveur : la commande est entièrement payée.

Les règles

La commande n'est ni livrée, ni annulée, ni entièrement payée.
Le nouveau total n'est pas inférieur à ce qui est déjà encaissé.
Au moins une ligne, avec des quantités supérieures à 0.
Livreur : pas plus que le stock disponible dans le van.
Une ligne existante garde son prix ; un produit ajouté prend le prix prévu pour le client.
Correction associéeUne commande dont l'envoi a échoué reste marquée « non synchronisée ». Avant, elle pouvait être marquée envoyée à tort.
CHAPITRE 06

Saisir et lire les quantités en cartons

Gestion des données › Produits · écrans de saisie · application Pour : tous les utilisateurs
Où trouver cet écran
Réglage
Gestion des données›Produits›Modifier
Saisie web
Commercial›Ventes
Stock web
Gestion de stock›Mouvements / Gestion des Stocks
Téléphone
Clients›Vente ou Cmd
Téléphone
onglet Stock

Le réglage se fait une fois par produit dans Produits. Ensuite, l'aide en cartons apparaît toute seule sur les écrans de saisie.

Partout où vous tapez une quantité, vous pouvez la saisir en cartons + unités. Le logiciel convertit tout seul en unités : le stock reste compté en unités, le carton sert à saisir et à lire plus vite.

2 cartons×24 u+3 u=51 unités

Indiquer le nombre d'unités par carton

  1. Ouvrez Gestion des données › Produits et cliquez sur Modifier à côté du produit.
  2. Remplissez Unités par carton (par exemple 24), puis cliquez sur Modifier le produit. Laissez vide si le produit ne se gère pas en carton.
  3. Cartons par colis est facultatif.

Saisir en cartons sur le web

Dès qu'un produit a un carton, une petite ligne cartons × N u + unités apparaît sous le champ Quantité. Tapez l'un ou l'autre : les deux restent synchronisés.

  1. Choisissez le produit.
  2. Tapez les cartons et les unités sous la quantité.
  3. Le total en unités s'affiche (= 51 u) et remplit le champ Quantité.

La même aide existe sur les écrans Vente, Caisse, Mouvements (transfert, perte, échantillon, retour fournisseur), Charger un van, Nouvel ajustement de stock, Commandes clients et Inventaire.

Lire le stock en cartons

Sous chaque quantité en stock, l'équivalent en cartons s'affiche : 50 pièces = 2 ct + 2 u. Sur la feuille de comptage d'inventaire, la colonne Cond. indique « ct de 24 » et les colonnes Cartons et Unités sont prêtes à remplir (chapitre 04).

Sur le téléphone

L'application suit les mêmes règles. Sur chaque ligne du panier ou de la commande, une ligne cartons × 24 + unités s'ajoute sous le compteur d'unités.

Bon à savoirLes limites de stock (stock du van, stock dépôt) et les prix restent calculés en unités. Un produit sans « Unités par carton » se saisit comme avant, en unités.
CHAPITRE 07

Vérifier le stock avant de prendre une commande

Application mobile › Clients › Cmd Pour : prévendeurs
Où trouver cet écran
Téléphone
onglet Clients›Cmd›Ajouter des produits›Afficher

Dans l'onglet Clients (en bas de l'écran), chaque client a un bouton bleu Cmd pour prendre une commande.

Le prévendeur voit sur son téléphone la quantité disponible au dépôt pour chaque produit. Il sait tout de suite s'il peut promettre la marchandise au client, sans appeler le magasin.

  1. Dans Clients, appuyez sur Cmd à côté du client.
  2. Sous Ajouter des produits, appuyez sur Afficher. Chaque produit indique son Stock dépôt.
  3. Ajoutez les produits et réglez les quantités : l'app vous empêche de dépasser le stock disponible.
AffichageSignificationCe que fait l'app
Stock dépôt : 119Plus de 5 unités disponiblesCommande libre jusqu'à ce stock
Stock dépôt : 35 unités ou moins : stock faiblePrévenez le client que la quantité est limitée
Rupture de stockPlus rien au dépôtProduit grisé ; l'ajout est refusé avec un message
Stock inconnuProduit pas encore synchroniséPas de limite ; synchronisez pour l'obtenir

D'où vient ce stock

  • C'est le stock de tous les entrepôts actifs, hors vans : la marchandise que le dépôt peut encore préparer pour une livraison.
  • Il est mis à jour à chaque synchronisation (automatique toutes les 2 minutes, ou bouton Sync). Sans réseau, l'app affiche le dernier stock connu.
  • Les produits gérés en cartons affichent aussi « carton de 24 » : voir le chapitre 06.
Le stock affiché n'est pas réservéDeux prévendeurs peuvent voir le même stock au même moment. Pour un produit en stock faible (orange), synchronisez juste avant de confirmer au client.
CHAPITRE 08

Fixer et suivre les objectifs des vendeurs

Rapports & Analyses › Objectifs vendeurs Pour : responsable commercial
Où trouver cet écran
Menu de gauche
Rapports & Analyses›Objectifs vendeurs

C'est la dernière entrée du menu Rapports & Analyses.

Chaque entrepôt correspond à une gamme de produits. Vous fixez donc à chaque vendeur un objectif de chiffre d'affaires par gamme et par mois, en général deux, et l'écran calcule son taux de réussite en continu.

CA réalisé÷objectif=taux de réussite

Avant de commencer : rattacher les produits à leur gamme

Un objectif « par entrepôt » compte le CA des produits rattachés à cet entrepôt. Sur chaque fiche produit, remplissez le champ Entrepôt / gamme (visible sur la capture du chapitre 06, à droite des cartons). Un produit sans gamme ne compte dans aucun objectif d'entrepôt.

Définir un objectif

  1. En haut, choisissez le mois et l'année : l'objectif porte sur cette période.
  2. Dans Définir un objectif, choisissez le vendeur.
  3. Laissez Périmètre sur « Entrepôt / gamme » et choisissez l'entrepôt. (« Type de produit » permet aussi un objectif par catégorie.)
  4. Tapez le montant de l'Objectif CA (TTC), puis cliquez sur Enregistrer.
  5. Recommencez pour la deuxième gamme. Un vendeur ne peut avoir qu'un seul objectif par entrepôt et par mois.
Gagner du temps chaque moisReprendre le mois précédent copie les objectifs du mois d'avant vers le mois affiché. Seuls ceux qui n'existent pas encore sont créés ; une confirmation vous est demandée.

Suivre les résultats

  1. Les tuiles résument le mois : objectifs définis, objectifs atteints, CA réalisé et taux global.
  2. Le tableau Suivi du mois regroupe les objectifs par vendeur, avec son taux global sur ses deux gammes.
  3. Pour chaque gamme : objectif, CA réalisé, reste à faire et barre de progression. Le badge Atteint apparaît à 100 %.
  4. Les boutons à droite servent à modifier ou supprimer un objectif.
moins de 60 % de 60 à 99 % 100 % et plus : Atteint

Ce qui compte dans le CA réalisé

  • Les ventes de tournée du vendeur et les commandes qu'il a prises (hors commandes annulées), en TTC, sur le mois de l'objectif.
  • Seuls les produits de la gamme de l'objectif sont comptés.
  • Livrer une commande ne crée pas de vente : rien n'est compté deux fois.
  • Les mêmes chiffres alimentent le taux de réalisation du chapitre 02.
CHAPITRE 09

Suivre l'état des livreurs : net ou écart

Distribution › État des livreurs Pour : responsable, caissier
Où trouver cet écran
Menu de gauche
Distribution›État des livreurs

C'est la troisième entrée du menu Distribution, juste sous Tournées.

À la fin de chaque tournée, le livreur rend l'argent et un rapport de caisse est validé. Cet écran compare, pour chaque livreur, l'argent rapporté à l'argent attendu, et dit en un coup d'œil s'il est net ou s'il présente un écart.

fonds de départ+espèces encaissées−dépenses=attendu rapporté−attendu=écart
ÉtatSignificationQue faire
NetSur toutes ses tournées terminées, l'argent rapporté correspond à l'argent attendu, à 10 DA près.Rien.
ÉcartAu moins une tournée avec un manquant (rapporté < attendu) ou un excédent (rapporté > attendu).Ouvrez le détail, lisez la justification, régularisez avec le livreur.
À contrôlerUne tournée terminée n'a pas de rapport de caisse, ou son rapport n'est pas encore validé.Faites saisir et valider le rapport de caisse.
Aucune tournéePas de tournée terminée sur la période.Masqué par défaut ; cochez « Afficher les livreurs sans tournée ».
  1. Choisissez la période : dates Du / Au, ou les raccourcis 7 jours, 30 jours, Ce mois. Par défaut : les 30 derniers jours.
  2. Lisez les tuiles : nombre de livreurs en écart, à contrôler et nets, et le manquant total. Cliquez sur une tuile pour n'afficher que ces livreurs.
  3. Dans le tableau, chaque livreur a son état, son manquant, son excédent et son écart net (rouge : il manque de l'argent ; bleu : il y en a trop). Les livreurs en écart sont en haut.
  4. Cliquez sur Voir le détail pour ouvrir le détail de ses tournées.

Lire le détail d'un écart

  1. Une ligne par tournée, la plus récente en haut : fonds de départ + espèces − dépenses = attendu, puis ce qui a été rapporté et l'écart.
  2. Sous la tournée : qui a validé le rapport, la justification saisie pour l'écart et les billets rendus.
  • Seules les tournées terminées ou clôturées comptent. Une tournée en cours n'a pas encore de résultat.
  • Les paiements par carte, chèque ou à crédit ne sont pas de l'argent à rapporter : ils ne créent pas d'écart.
  • Un écart de 10 DA ou moins est toléré (arrondis, monnaie) : le livreur reste « Net ».
  • Si un livreur a à la fois un écart et une tournée à contrôler, il apparaît en Écart : c'est le plus urgent.
D'où viennent les chiffresDu rapport de caisse de chaque tournée (fonds de départ, encaissements, dépenses, argent rendu, justification). Les mêmes rapports restent consultables dans Rapports & Analyses › Historique tournées.
CHAPITRE 10

Tableau des bénéfices protégé par code PIN

Rapports & Analyses › Rapport des Bénéfices Pour : administrateur de l'entreprise uniquement
Où trouver cet écran
Menu de gauche
Rapports & Analyses›Rapport des Bénéfices

L'entrée porte un petit cadenas. Elle n'apparaît que pour les comptes dont le rôle dans l'entreprise est Administrateur.

Les bénéfices sont une information sensible : seul l'administrateur de l'entreprise peut les voir, et il doit saisir un code PIN à chaque ouverture. Le PIN est commun à tous les administrateurs de l'entreprise.

Première ouverture : choisir le code PIN

  1. Le premier administrateur qui ouvre la page choisit le code : 4 à 8 chiffres, tapé deux fois.
  2. Cliquez sur Enregistrer le code PIN. Le tableau s'ouvre, et le code vaut désormais pour tous les administrateurs de l'entreprise. Communiquez-le-leur de vive voix.

Ouvrir le tableau

  1. Tapez le code PIN, puis Déverrouiller.
  2. En cas d'erreur, le nombre d'essais restants s'affiche. Après 5 erreurs, l'accès est bloqué 15 minutes pour toute l'entreprise, même avec le bon code.
  1. Une fois le PIN accepté, l'accès reste ouvert 15 minutes sur cet ordinateur : vous pouvez changer de page et revenir sans retaper le code.
  2. Verrouiller referme le tableau tout de suite (à faire en quittant votre poste). Changer le code PIN demande l'ancien code, puis le nouveau deux fois.
  3. Les exports Excel et PDF ne fonctionnent que pendant que le tableau est ouvert.

Pour les autres utilisateurs

  • Seul le rôle Administrateur de l'entreprise donne accès. Un compte « staff » sans ce rôle est refusé.
  • Chaque administrateur ne voit que les bénéfices de son entreprise.
  • Le code PIN est enregistré chiffré : personne, même un informaticien qui lit la base, ne peut le relire.
  • Chaque ouverture, erreur de code et changement de code est noté dans Rapports & Analyses › Journaux d'audit.
